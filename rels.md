# AllCalc v4.3.0

## What's New

### New Language Support
- **French (`fr`)**: Added full French localization in `modules/language/fr.json` (77 translation keys). You can switch to French anytime in **Settings -> Language** (`fr`).
- **Documentation**: Updated `README.md` to include French (`fr - Français`) in the list of supported languages.

### Maintenance
- **Version Bump**: Updated version to `4.3.0`.

## Installation

### Via pip
```bash
pip install allcalc
```

### Via install script (Linux only)
```bash
curl -fsSL https://raw.githubusercontent.com/DenisVargaeu/allcalc/refs/heads/main/install.sh | bash
```
